# OdyRush · 池袋 IMAX 抢座助手

**仅适用于 Grand Cinema Sunshine 池袋 IMAX 12 号厅。** 当前版本：**0.6.0**。

自动识别座位页、挑选 1–6 人同排连座，并进入票种选择页；支持中央区域／全场、高级座位开关，以及后台失败标签自动关闭。**选择票种和付款需要自己完成，不保证抢票成功。**

## 第一步：安装 Tampermonkey

以下步骤以 **Windows + Chrome** 为例，不需要安装 Node.js，也不需要懂代码。

1. 用 Chrome 打开 [Tampermonkey 扩展商店页面](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)。
2. 点击 **添加至 Chrome → 添加扩展程序**。
3. 在地址栏输入 `chrome://extensions`，按回车。
4. 找到 **Tampermonkey → 详细信息**，打开 **允许用户脚本（Allow User Scripts）**。旧版 Chrome 如果没有这个选项，可按 [官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)开启扩展页面右上角的开发者模式。
5. 点击 Chrome 右上角的拼图图标，把 Tampermonkey **固定到工具栏**，方便之后打开。

## 第二步：安装 OdyRush 脚本

1. 点击 **[安装 OdyRush](https://raw.githubusercontent.com/wjin999/OdyRush/main/OdyRush.user.js)**。
2. 如果弹出 Tampermonkey 安装页面，确认脚本名是 **OdyRush - Grand Cinema Sunshine**，点击 **安装**。
3. 点击工具栏上的 Tampermonkey 图标，进入 **管理面板**，确认 OdyRush 已启用。

**如果第 1 步只显示代码，没有安装按钮：**

1. 在代码页面按 `Ctrl + A` 全选，再按 `Ctrl + C` 复制。
2. 点击 Tampermonkey 图标 → **添加新脚本／创建新脚本**。
3. 在编辑器里按 `Ctrl + A`，删除默认示例，再按 `Ctrl + V` 粘贴完整代码。
4. 按 `Ctrl + S` 保存，回到管理面板确认脚本已启用。

## 第三步：提前设置好人数和范围

1. 打开 [池袋影院场次页](https://www.cinemasunshine.co.jp/theater/gdcs/#schedule)。如果之前已打开，先刷新。
2. 页面右上角出现 **OdyRush** 面板，就说明脚本开始运行了。
3. 按自己的需求设置下表。设置会自动保存，并在新购票标签中读取。
4. 找到要看的电影、日期和 **IMAX／12 号厅**场次，核对时间。需要登录时提前完成登录。

| 设置 | 建议初始值 | 作用 |
| --- | --- | --- |
| 人数 | 按实际人数填写 | 支持 1–6 人，只选同排连续座位，不跨过道 |
| 选座区域 | 中央区域 | 只选 G–R 排中央座块；选“全场”后也考虑前排和两侧 |
| 高级座位 | 关闭 | 只选普通座位；开启后允许需要加价的 Premium／Grand Class |
| 自动选座 | 进入后自动执行 | 进入匹配的座位页后，自动分析并选座 |
| 失败标签 | 后台自动关闭 | 自动关闭符合条件的后台失败页面 |

**中央区域没有连座就停止，不会擅自改选全场。** 高级座位开关只是允许选择更贵的座位，不代表优先选更贵的座位。

## 第四步：推荐抢座方法——Ctrl + 左键，多标签后台打开

1. 留在影院场次页，确认 **自动选座** 和 **后台自动关闭** 已开启。
2. 场次开放购票后，**按住 `Ctrl` 不松开，用鼠标左键连续点击同一场次的购票链接**。每点击一次会在后台打开一个标签；可以先开几个，例如 3–5 个。
3. 松开 `Ctrl`，保持原场次页在前台，让新打开的页面在后台加载和判断。
4. 脚本会识别每个页面：进入匹配的选座页后，等待座位表就绪，再自动选座；出现明确错误、访问拥堵或 Cookie 受限的托管后台页面会自动关闭。
5. 同场次只会有一个标签执行选座，其他标签排队；前一个失败、停止或关闭后，后一个接替。已有标签成功后，其他标签会停止重复选座。
6. 看到标题带有 **✅ 已进入下一步** 的标签，切换过去，核对场次、座位和价格，**手动选择票种并完成付款**。成功标签和等待标签不会自动切到前台，需要自己查看。

> **“没进去就关”仅指明确失败的页面。** 正在加载、普通登录或验证码页面会保留；正在前台查看的页面、不是通过脚本托管打开的页面也不会自动关闭。脚本不会绕过登录、验证码或网站拥堵限制。

如果只想自己决定何时开始，把“自动选座”改为 **仅手动执行**；进入座位页后，点击 **自动分析并选座** 即可。该按钮同样会在选座后勾选利用规约并点击“次へ”，不是仅预览。

## 它会选哪些座位？

优先考虑 **M 排附近、银幕中轴附近的连座**。全部空座时，双人首选 **M20、M21**；同时比较邻近排，避免为了选 M 排而坐得过于偏侧。高级座位的价格不会增加评分。

“中央区域”对应以下座位，不包括 A–F 排和两侧座块。本厅没有 I、L 排。

| 排 | 中央区域座号 | 类型 |
| --- | --- | --- |
| H、J、K、M、O、P、Q | 11–30 | 普通座位 |
| G、N | 11–22 | Premium Class，需开启高级座位 |
| R | 11–20 | Grand Class，需开启高级座位 |

推荐根据排位置、实际显示坐标和连座情况计算，是观影偏好估计，不是官方最佳座位认证。脚本读取网页里的座号与可选状态，不靠截图识别。完整评分、页面判断和多标签机制见 [选座规则与实现说明](docs/selection-rules.md)。

## 常见问题

| 遇到的情况 | 怎么处理 |
| --- | --- |
| 没有出现 OdyRush 面板 | 确认正在池袋场次页；检查 Tampermonkey、OdyRush 和“允许用户脚本”都已开启，然后刷新 |
| 没有自动选座 | 检查是否开启自动选座、是否为 12 号厅；页面可能还在加载，先看面板提示 |
| 提示布局不符或等待超时 | 最多等待 30 秒；确认是 IMAX 12 号厅，待加载完成后再点按钮。持续不符请反馈，勿强行套用其他厅 |
| 提示没有合适连座 | 可以减少人数，或自行改为“全场”／允许高级座位，再点击按钮；这些设置不会自动放宽 |
| 提示无法确认场次编号 | 不会自动执行；先核对场次，再手动点击按钮 |
| 想停止或选座中途失败 | 点击“停止”；已选座位会保留。先人工检查、取消已有选座，再重试 |
| 提示已有标签完成选座 | 到成功标签继续购票；同场次成功后 15 分钟内会阻止重复执行，手动按钮也受此限制 |
| 失败页没有关闭 | 确认它是 Ctrl + 左键托管打开、处于后台且命中明确失败类型；登录和验证码请人工处理 |

## 更新脚本

1. 再次打开 [安装链接](https://raw.githubusercontent.com/wjin999/OdyRush/main/OdyRush.user.js)，按 Tampermonkey 提示更新。
2. 如果使用手动粘贴方式，到 **管理面板 → OdyRush**，用最新版完整代码替换旧内容，按 `Ctrl + S` 保存。不要同时启用两份 OdyRush。
3. 刷新影院场次页。旧标签仍可能运行旧版本，下一次抢座请重新打开购票标签。

## 验证与反馈

目前通过 **29 项自动测试**及 JavaScript 语法检查。流程测试使用模拟网页，尚未在真实影院完成占座验证；网站改版后可能需要更新脚本。

发现问题可在 [GitHub Issues](https://github.com/wjin999/OdyRush/issues) 描述操作步骤、面板提示和浏览器版本。截图请遮住账号、订单号及其他个人信息。

开发者可运行 `npm test` 和 `node --check OdyRush.user.js`；普通用户不需要执行这些命令。
